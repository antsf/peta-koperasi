# Session Notes — 2026-08-04

## What was done

### Map points not showing (FIXED)
- **Root cause:** `leaflet.markercluster` CJS plugin can't resolve its `leaflet` peer dep through Turbopack dynamic imports. `L.markerClusterGroup` was undefined, error caught silently, no markers rendered.
- **Fix:** Removed markercluster entirely. Map now uses plain `L.marker().addTo(map)`. Markers are tracked in `markersRef` and cleared on each fetch.
- **Note:** markercluster deps still in package.json — need to remove them.

### Name change
- "Peta Koperasi Merah Putih" → "Peta Koperasi Desa Merah Putih" in all files (id.json, en.json, submit/pending/point pages)

### Footer not fixed to viewport (FIXED)
- **Problem:** Footer was pinned at viewport bottom on all pages due to `flex-1 overflow-y-auto` on page wrappers creating internal scroll contexts.
- **Fix:** Changed `h-full` → `min-h-full` on html/body. Removed `min-h-0` from main. Removed `overflow-y-auto` from submit/pending/point pages. Content flows naturally, footer sits below.
- **Home page:** Uses `calc(100vh - 4rem)` to keep map filling viewport.

### Photo preview on submit form (ADDED)
- Added `photoPreview` state with `URL.createObjectURL` for instant preview
- Shows preview image (h-48, rounded) with red delete button (X)
- Properly revokes object URLs on cleanup
